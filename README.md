# Apraxus

Apraxus is an independent blockchain project focused on building a secure, transparent, and verifiable blockchain infrastructure.

## Current Status

🚧 Early development

The current repository contains the initial Apraxus blockchain node implementation, including:

- Block creation
- Blockchain validation
- Transactions
- Wallets
- Balance tracking
- Cryptographic integrity checks

## Technology

- Rust
- SHA-256 hashing
- Custom blockchain architecture

## Vision

Apraxus is being developed as a foundation for a decentralized blockchain ecosystem.

More details will be published as development progresses.
